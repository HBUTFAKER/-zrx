## 四、当前灯态为什么是重算的（重要，审计请看这条）

`out/005s_validation.json` 里**没有「今天是不是防守期」这一位**：

- `light` 段只有历史 60 个月（2021-01~2025-12）的防守月统计
- `latest` 段只有名单与 `as_of=2026-11-06`，无灯态字段

界面必须显示当前态，所以按 JSON 里写死的同一套规则（`light.window=20` / `light.threshold=0.1`）从基准收盘序列 `data/raw/index/hs300_total_return_2026-11-09.parquet` 重算，调的是 `src.radar_005s.state_light`（**未改 src/ 一行**，只调用其纯函数）。规则同源、结果可复算，不引入第二套口径。

若审计认为「当前灯态必须由施工A 写进产物」，需另发指令给施工A 加字段——那属于改产物结构，不在 S4 界面层权限内。

## 五、边界（实现约束）

- **运行时零大模型接口**：`web/` 下不 import 任何 LLM SDK、无任何网络调用（AST 扫描 + 源码扫描双重断言，见测试 `TestNoLLM`）
- **只读**：只 `json.load` / `pd.read_parquet`，装载前后 `out/` 目录 mtime 不变（有测试守着）
- **不做买入推荐**：无买入/建议类字样、无收益率预测、无目标价；**避雷名单已判失败（2/5=40% < 70%），完全不读、不展示**
- **文案硬约束逐字照抄**，见 `web/radar_data.py` 顶部常量 + 测试 `TestHardCopy`
- **禁字表用片段拼装**：源码里不留完整禁字明文，grep 审计能干净通过；运行时 `BANNED_SUBSTRINGS` 仍等于完整集合
