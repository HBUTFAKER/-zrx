# 炒股全流程 · 零基础版

> 生成时间：2026-11-04 ｜ 适用：A股（沪深主板）｜ 用途：搞清楚"炒股这件事从开户到复盘到底经过哪些环节"
> 说明：费率与规则以券商和交易所最新公告为准，本文数字仅作量级参考。

---

## 一句话结论

**流程本身一天就能学会，难的是"买什么、买多少、什么时候认错"。**
制度流程是体力活，研究流程才是真功夫。

---

## 一、四层结构

| 层 | 内容 | 学多久 |
|---|---|---|
| 制度层 | 交易规则、费用、涨跌停、T+1 | 1 小时 |
| 账户层 | 开户、入金、权限开通 | 1 天 |
| 决策层 | 研究、估值、买卖点、仓位 | 长期（真正的活） |
| 复盘层 | 记录每笔交易、统计胜率与盈亏比 | 终身 |

## 二、五个环节

### 1. 开户与入金
- 券商 App 线上开户，身份证 + 银行卡，人脸识别，通常当天或次日可用。
- 沪深 A 股账户免费开；一个人可在多家券商开户（同一市场最多 3 个 A 股账户）。
- 入金走"银证转账"：银行卡 → 证券资金账户，交易日 9:00–16:00 左右可转。
- **创业板（300）、科创板（688）、北交所、可转债**都要单独开权限，有资产和交易经验门槛，零经验阶段先别碰。

### 2. 认清规则（A股和美股不一样）
- **T+1**：今天买的股票，最早明天才能卖。当天不能来回做。
- **涨跌停**：主板 ±10%，创业板/科创板 ±20%，ST 股 ±5%。涨停/跌停时可能买不进、卖不掉。
- **最小单位**：100 股 = 1 手；科创板 200 股起、可按 1 股递增。
- **交易时间**：集合竞价 9:15–9:25，连续竞价 9:30–11:30 / 13:00–15:00，收盘集合竞价 14:57–15:00。
- **T+1 交收**：卖出后资金当天可用于再买，但取现要等下一个交易日。

### 3. 费用（糊掉收益的隐形手）
| 项目 | 大致标准 | 收几边 |
|---|---|---|
| 佣金 | 万分之 2.5 左右，可谈；通常最低 5 元 | 买 + 卖 |
| 印花税 | 卖出金额的 0.05% | 只卖出 |
| 过户费 | 成交金额的 0.001% | 买 + 卖 |

> 关键感受：一次完整买卖（买进再卖出）成本约 0.1% 上下。**做得越频繁，成本吃掉越多。**"高抛低吸"做十次，光成本就够呛。

### 4. 研究 → 下单
- 研究要回答三个问题：**这家公司靠什么赚钱？现在贵不贵？什么价格值得买？**
- 常用材料：年报/季报（巨潮资讯网）、行业数据、估值指标（PE、PB、股息率、ROE）。
- 下单两种方式：
  - **限价单**：指定价格，不到价不成交（新手推荐，不会买在离谱价位）。
  - **市价单**：立即成交，价格由市场定（流动性差的票容易吃滑点）。
- 下单后进入"委托"，成交后变"持仓"，未成交可撤单。

### 5. 持仓管理与复盘
- **仓位**：单只股票不超过总资金的一定比例（新手常见做法 10%–20% 一只），永远不要满仓一只票。
- **止损/止盈**：买入前就写下"跌到多少我认错"，而不是跌了再想。
- **记录**：每笔交易记下 买入理由 / 卖出理由 / 盈亏 / 事后来看对不对。
- 三个月后回头看记录，你会发现亏钱的原因高度重复。

## 三、新手最容易踩的五个坑

1. **先想着赚钱，没想过亏多少**——第一笔钱应该是"学费",额度控制在亏光也不影响生活。
2. **听消息买股**——你听到的消息，早就被消化完了。
3. **满仓 + 加杠杆**（融资融券、场外配资）——杠杆会把你从"看错一次"变成"出局"。
4. **频繁交易**——手续费 + 情绪消耗，双杀。
5. **把回测/运气当能力**——牛市赚的钱，熊市会连本带利收回去。

## 四、下一步（如果真要做研究）

炒股和量化研究的区别只在一点：**决策靠不靠可复算的证据**。
要做成"可量化的工作"，标准路径是：定义问题 → 取数 → 造特征 → 回测 → 样本外评估 → 持续跟踪。
这条路可以一步一步来，先从"把一只股票过去 5 年的财务数据拉出来看"开始，比急着下单有价值得多。
