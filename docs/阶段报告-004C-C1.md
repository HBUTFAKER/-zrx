## 一、做了什么

新增 C1 的四个低波动因子，并按 C4 硬闸逐窗口判定；顺带把 C2 的三个反转窗口一起算了（同一套 IC 管线，省一次全量载入）。

| 因子 | 定义 | 定向 |
|---|---|---|
| `lowvol_20` / `60` / `120` | 过去 N 个交易日**日收益**标准差（hfq 价） | 取负号，值越大 = 波动越低 = 越优 |
| `turn_stab_60` | 过去 60 日**换手率**标准差 | 取负号，值越大 = 换手越稳 = 越优 |
| `reversal_20` / `40` / `60` | 过去 N 日跌幅（＝动量取负） | 取负号，值越大 = 跌得越多 = 越优 |

实现细节（都写了注释，便于审计）：

- 全部走 `_shift1`，T 日值只用 ≤T-1 数据，与模块既有口径一致
- 用 hfq 价不用原始价：除权日假跌幅会被记成波动，低波因子会专挑正在分红的票
- 滚动标准差 `min_periods = window`：窗口里少一天（停牌 / hfq 缺口 / 上市不足）→ 整窗 NaN，**不插补**。这就是指令里「不足 60 日排除」的物理实现
- `turn ≤ 0` 先置 NaN 再滚动：停牌日是「没有交易」，不是「换手率为零」，否则停牌多的票会被误判成「很稳定」
- **方向在因子层就取好负号**，下游 IC 为正即等于「方向为正」，C4 不必再解释符号

## 五、结论

1. **`lowvol_20` 是 C1 里唯一 4/5 窗口过 C4 的因子**，是低波动这组的主力。W1（2019~2020 训练段）不过：那两年是成长股牛市，低波动天然跑输，`t=+1.46` 不算难看但不够 2.0。
2. **`lowvol_60` 的 W5 差 0.02** （t=+1.98，阈值 2.0）。这是边界值，**不调参、不放宽**，按落选记录。真要说是"卡在门槛上"，不是"刚好过"。
3. **窗口越短越强**：20 日 > 60 日 > 120 日，三个窗口单调。这说明短周期波动里的定价错误更明显，也意味着因子换手会更高（成本要盯）。
4. **换手稳定性只有 2/5 过闸**，比预期弱。数据可用（覆盖 97%+），但显著性不够，`t` 在 1.42~2.35 之间。
5. C2 的主窗口逐窗口选择结果：**20 / 40 / 40 / 40 / 60 日，方向 5 个窗口全部是反转**（没有一次翻成动量）。W2、W5 的主窗口 t 值 < 2，即反转在这两个训练段不显著，但因为 IC 仍为正，方向冻结为反转。
