## 1. 它解决什么问题

**你的真实需求**：0 经验，想看清"量化到底怎么把炒股变成可复算的工作"，并且要能自己拿主意的依据。

所以这个 App 的核心不是"预测涨跌"，是三件事：

1. **透明**：每个指标点一下，弹出它的口径、数据来源、计算公式、样本区间、局限。
2. **可复算**：同样的数据 + 同样的参数，任何人重跑得到同样的数字（连手续费算法都要写清）。
3. **可对账**：你每次决策都留档，三个月后回来看"当时那些证据站不站得住"。

**明确不做**：不做实时行情推送、不做自动下单、不做"AI 预测明日涨跌"、不做社交/跟单。

## 2. 信息架构：5 个页面

### P1 · 个股透视（主力页面）
输入一个代码（如 `600519`），看到：
- **价格区**：K 线（前复权）、成交量、均线；下方标注除权日、停牌区间
- **估值区**：PE-TTM / PB 当前值 + **近 10 年历史分位数**（这是判断"贵不贵"最实用的一个图）
- **基本面区**：营收/净利/ROE/毛利率/资产负债率，近 8 个季度 + 近 10 年年度
- **同行对比**：同行业 10 家公司的 PE/PB/ROE 排名表
- **证据卡**：见第 4 节（本页最重要的产物）
- **溯源按钮**：每个数字右侧一个 `ⓘ`，点开显示「来源文件 / 字段 / 公式 / 区间 / 已知问题」

### P2 · 因子实验室
选一个因子（如"低 PE""20 日动量""ROE 连续 3 年 > 15%"），跑一次全市场回测：
- 参数面板：股票池、时间区间、调仓频率、持仓只数、手续费开关
- 结果：净值曲线（叠加沪深 300 基准）、分年度收益表、指标卡
- **必显示**：样本内 / 样本外分界竖线，以及两段的指标对照
- **必显示**：参数敏感性热力图（看它是"高原"还是"尖峰"）

### P3 · 全市场扫描
把 P2 的因子套到全市场，输出候选池排名表：代码 / 名称 / 行业 / 触发因子值 / 各因子分位 / 数据完整度。
**排序不等于推荐**，表头写死"以下为条件筛选结果，非买入建议"。

### P4 · 决策台账
- 记一笔：代码、日期、动作（观察/试仓/加/减/清）、**当时理由**、依据的证据编号
- 自动抓取当日收盘价，之后每个交易日更新浮动盈亏
- 回看视图：每笔记录旁列出"当时的证据卡快照"——这是最值钱的功能，防止事后自我美化

### P5 · 方法论说明
不是文档堆砌，是把每个指标做成一页卡片：定义 / 公式 / 为什么这么算 / 什么时候会失效。
例如"为什么用后复权算回测、前复权看盘"、"为什么 T+1 必须在回测里体现"。

## 3. 数据层设计（决定成败，别赶工）

### 3.1 数据源（全部免费、本地缓存）

| 源 | 用途 | 说明 |
|---|---|---|
| **baostock** | 日线行情、季频财务、复权因子、是否 ST | 免费、无需 token、稳定，**首选底座** |
| **akshare** | 行业分类、指数成分、股东、龙虎榜、指数行情 | 免费、覆盖广，作为补充 |
| tushare（可选） | 更干净的财务数据 | 需积分，有则用 |

> 不接付费源、不接券商接口、不接爬虫抓的论坛情绪数据（无法溯源、无法复现）。

### 3.2 目录与表

```
quant_app/
├─ data/
│  ├─ raw/                    # 原始落地文件，只增不改，文件名带抓取日期
│  ├─ cache.db                # SQLite：清洗后的宽表
│  └─ dict.md                 # 字段字典（每个字段中文名/单位/口径/来源）
├─ src/
│  ├─ ingest.py               # 抓取 + 落地 + 增量更新
│  ├─ clean.py                # 复权、去重、停牌标记、ST 标记
│  ├─ factors.py              # 因子构造（强制滞后）
│  ├─ backtest.py             # 轻量回测引擎（自己写，别引重框架）
│  ├─ metrics.py              # 指标计算
│  ├─ evidence.py             # 证据卡生成
│  └─ api/main.py             # FastAPI 只读取结果，不做计算
├─ web/                       # 前端
├─ out/                       # 每次分析的结果快照（json + 图）
└─ tests/                     # 复算一致性测试
```

### 3.3 五条数据纪律（写进代码注释）

1. **时点对齐**：财报用**公告日**而非报告期，避免"提前知道"。T 日收盘后才能用的数据，信号只能在 T+1 执行。
2. **复权**：回测用后复权价（前复权会让老价格变负、收益率失真）；界面展示用前复权。
3. **停牌**：停牌日不产生成交，回测跳过。
4. **生存偏差**：股票池必须含已退市股票，不能用"今天的成分股"回测十年前。
5. **涨跌停**：一字涨停不可买、跌停不可卖，回测必须模拟。

## 4. 证据卡：把"有理有据"落成固定格式

每只股票输出一张卡，结构固定，不许自由发挥：

```
【结论标签】可研究 / 观察 / 回避          （不是买入卖出）
【置信度】中 ｜ 理由：数据完整度 92%，但盈利质量存在分歧

看多证据（每条必须带数字 + 出处 + 截止日期）
 1. ROE 连续 8 季 > 20%，行业排名 3/46        来源：季报，截至 2026Q2
 2. PE-TTM 18.3，处于近 10 年 12% 分位         来源：日行情，截至 2026-11-03
 3. 经营现金流 / 净利润 = 1.24，利润含金量高   来源：近 4 季累计

看空证据（同上，必须带数字）
 1. 营收增速从 22% 降至 6%，连续 3 季下滑
 2. 应收账款周转天数从 45 升至 78 天

数据缺口（必须老实列）
 - 2025 年报未披露，最新完整年度数据滞后
 - 无券商研报一致预期数据，无法做 forward PE

一句话总结：证据支持"值得进一步研究"，不支持"现在就买"。
```

**关键设计**：看多和看空各不少于 2 条、不多于 4 条，且**两边都必须有**。这是防止工具变成"看涨回音壁"的机制。

## 5. 计算层规范

### 5.1 回测引擎（自己写，约 300 行）

| 项 | 规则 |
|---|---|
| 信号 | T 日收盘后用数据算，**T+1 开盘价**成交 |
| 交易限制 | 涨停不买、跌停不卖、停牌跳过 |
| 成本 | 佣金 0.025%（双边，最低 5 元）、印花税 0.05%（仅卖出）、过户费 0.001%（双边） |
| 持仓 | T+1 才能卖；持仓只数、单只权重上限可配 |
| 基准 | 沪深 300 全收益 + 等权全市场，两个都要给 |

### 5.2 必出指标（缺一不算完成）

年化收益 / 年化波动 / **最大回撤** / 夏普（无风险 2%）/ 卡玛 / 胜率 / 盈亏比 / 年换手率 / 超额收益（vs 基准）/ **分年度收益表** / 样本外表现

> 只报年化收益不报最大回撤的报告，一律视为不合格。

### 5.3 验证设计（防自欺）

- **时间切分不随机打乱**：样本内 2015–2021，样本外 2022–至今，界线上必须画出来
- **Walk-forward**：滚动窗口重训重测，看稳定性
- **参数敏感性**：主要参数做网格，看结果是"一片高原"还是"一根针"（针 = 过拟合）
- **对照基线**：任何策略必须对比「买入持有沪深300」和「等权全市场」，跑不过就别吹

## 6. 技术栈与工期

**MVP（先跑起来，1–2 天量级）**
- Python 3.11 + pandas / numpy + baostock
- **Streamlit** 单文件界面（快、能画图、够用）
- SQLite 缓存
- 只做 P1 精简版（价格 + 估值分位 + 证据卡）+ P2 单因子回测

**二期**（体验升级）
- FastAPI 后端 + React/Vite + ECharts 前端
- P3 全市场扫描、P4 决策台账
- 结果快照落 `out/`，支持历史对比

**为什么不直接上 React**：先用 Streamlit 把"算得对不对"验证掉，界面是最后一步。顺序反了会做出一堆好看的空壳。

## 11. 研究问题候选清单（供选定第一期课题）

选型原则：**先用"只依赖价格数据"的问题把整条管线跑通，再逐步引入财务数据、退市股票、代理变量**。
不要一上来做最难的问题，否则会被数据清洗拖死，最后连一个结论都出不来。

| # | 研究问题 | 一句话结论方向 | 数据依赖 | 难度 | 主要教学价值 |
|---|---|---|---|---|---|
| Q1 | A 股短期动量是正还是负？ | 大概率**反转**占优 | 仅日线 | ★ | 打脸"美股策略搬来就能用" |
| Q2 | 交易成本能吃掉多少收益？ | 换手越高衰减越陡 | 仅日线 | ★ | 建立成本意识，最实用 |
| Q3 | 低估值（低 PE/PB）还灵不灵？ | 分年度差异巨大 | 日线 + PE/PB | ★★ | 看见风格切换与价值陷阱 |
| Q4 | 高 ROE 公司能跑赢吗？ | 取决于买入价格 | 日线 + 季度财务 | ★★★ | "好公司≠好股票"，未来函数高发区 |
| Q5 | 小市值因子还在吗？ | 2017 后显著走弱 | 全 A + 退市股 | ★★★★ | 生存偏差 + 制度变化杀死因子 |

### 推荐顺序：Q1 → Q2 → Q3 → Q4 → Q5

理由：难度阶梯与数据依赖一致，每一层只增加一个新变量（Q1 加价格；Q2 加成本；Q3 加估值；Q4 加财报与时点；Q5 加退市与制度）。每完成一级，管线能力增加一层，且上一级的结论不会被推翻。

> **不要跳过 Q1/Q2 直接做 Q4/Q5**。前两个问题的代码量只占总量的 20%，却能验证回测引擎对不对——引擎不准则后面全白做。

## 12. 五个研究问题详解（选定后另开任务书）

### Q1 · A 股短期动量是正还是负？

**问题表述**：按过去 N 日（10/20/60 日）涨幅排序，买入最强者、卖空/回避最弱者，能否获得超额收益？

**背景**：动量效应（Momentum）是美股最稳健的异象之一（Jegadeesh & Titman, 1993）。但大量针对 A 股的研究发现方向相反——**短期反转**更强。直觉解释：A 股散户占比高、追涨情绪剧烈，涨多了就有人兑现，缺乏机构资金的持续推动；同时 T+1 与涨跌停限制了套利。

**为什么做这个问题**：它是"舶来策略水土不服"最干净的标本。你亲手跑一遍，会看到同样的因子在美国是正的、在 A 股是负的——这一课比读十篇文章都扎实。而且只用日线数据，是所有问题里最好实现的。

**关键坑**：必须做多空对称测试（A 股散户没有便利的融券，纯做多结论会失真）；必须分年度看，别只看一个平均年化。

**预期**：短周期（5–20 日）大概率反转占优，长周期（半年以上）结论不稳。**但请让数据说话，不要预设结论。**

---

### Q2 · 交易成本能吃掉多少收益？

**问题表述**：同一个策略，在换手率 5%/月、20%/月、100%/月 三档下，扣除 A 股真实费率后，收益衰减有多陡？

**背景**：散户回测最常见的自欺——回测年化 20%，实盘年化 3%。差额 90% 以上来自三样：滑点、手续费、印花税。A 股一次完整买卖成本约 0.1%（佣金双边 0.05% + 印花税 0.05% + 过户费 0.002%），一个月换手一次，年成本 1.2%；一个月换手四次，年成本近 5%——**这还没算滑点**。

**为什么做这个问题**：这是收益率最高的一个实验。它不教你赚钱，但能让你**不再亏不该亏的钱**。做完之后，"高抛低吸做短线"这句话在你眼里会自动换算成成本数字。

**关键坑**：滑点要单独参数化（按成交额的 0.05%–0.2% 试），别只算明面费率；要画出"成本 vs 换手"的曲线，而不是给一个数。

**预期**：高换手策略衰减极其陡峭，多数"高频小赚"策略扣完成本后归零。

---

### Q3 · 低估值（低 PE / PB）在 A 股还灵不灵？

**问题表述**：按 PE-TTM 或 PB 分位数把全 A 分五组，最低估值组相对最高估值组，超额收益有多少？分年度看呢？

**背景**：价值因子在美国有近百年证据。A 股的情况复杂：2016–2018 外资流入推白马，价值风格占优；2019–2021 成长风格（消费、医药、新能源）大胜，价值组跑输；2022 年后红利与"中特估"又起来。**平均年化会把这三种完全不同的世界压成一个数字，这是最危险的地方。**

**为什么做这个问题**：它第一次引入"估值数据"和"分年度拆解"，也是第一次直面**价值陷阱**——A 股低估值的常是银行、地产、钢铁，盈利在下滑，便宜是应该的。

**关键坑**：PE 为负的公司怎么处理（通常剔除或单列）；银行地产等行业 PB 天然低，要做行业中性化看结论是否还成立。

**预期**：长期正超额但年度波动极大；行业中性后超额明显缩水。

---

### Q4 · 高 ROE 的公司长期能跑赢吗？

**问题表述**：按 ROE（滚动 4 季）分五组，最高组持有 1 年，相对全市场等权的超额是多少？再叠加"买入时的估值分位"做二维分组。

**背景**：这是"买好公司"的量化版本，也是 2019–2021 年"核心资产"泡沫的注脚。当年的茅台、宁德、爱尔眼科 ROE 都很高，但 2021 年高点买入的人到 2024 年仍在亏。**问题不在公司好不好，在买入价格。**

**为什么做这个问题**：它第一次引入**财报数据**，而财报是未来函数的重灾区——用"报告期"对齐，等于提前 1–4 个月知道业绩；必须用**公告日**。这个坑踩过一次，一辈子忘不掉。

**关键坑**：公告日对齐；ROE 要用滚动 4 季而非单季；剔除上市不满 1 年的次新股（财务数据不稳定）；注意 ROE 高但现金流差的公司（财务造假样本，如某些已被处罚的案例）。

**预期**：高 ROE 组长期正超额，但叠加高估值买入后超额转负。**结论很可能是"好公司 + 好价格"才有效，单看 ROE 不够。**

### Q5 · 小市值因子在 A 股还存在吗？

**问题表述**：按总市值分五组，最小市值组相对最大市值组的超额，2010–2016 与 2017 至今两段分别是什么？含退市股票后还剩多少？

**背景**：2010–2016 年，A 股小市值是"神话"，年化超额惊人，背后是壳资源价值与并购重组预期。2017 年 IPO 常态化、退市趋严、注册制推进后大幅走弱。这是**制度变化杀死因子**的教科书案例。

**为什么做这个问题**：它是全清单里数据最难、也最能长本事的一个。**不包含退市股票的小市值回测，收益会被系统性高估**——因为退市股大多是小市值、且最终归零，把它们从样本里删掉，等于只留下了幸存者。做完这个，你对"回测数字"的信任度会永久性下降，这是好事。

**关键坑**：必须自建退市清单；必须处理停牌与 ST；必须做行业与上市年限中性；分段结论比整体结论重要。

**预期**：2017 年后超额显著收窄，含退市股后进一步下降。

---

## 13. 选型建议

**第一期做 Q1（动量/反转）或 Q2（成本敏感性）。**

- 两者都只依赖日线数据，一天内可以跑出第一张净值和第一张指标卡
- 都能立刻验证回测引擎是否正确（T+1、涨跌停、手续费）
- 都不需要处理财报与退市股票，不会被数据清洗淹没

跑通之后再按 Q3 → Q4 → Q5 逐级加难度。**每一级只增加一个新变量**，这是控制复杂度的唯一办法。
