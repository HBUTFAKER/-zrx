## 一、S1 状态灯（规则由本段提案，待总工验收）

- 日频：H00300 收盘 / 过去 **20 个交易日**最高收盘 − 1 ≤ **−10%** → 防守期；否则正常期
- 月频：**任一交易日**亮 = 该月为防守月（§二 口径）

## 十、005S-R2 整改：T+1 未来函数（审计C B8-B）

**问题**：`build_universe` 原来除了剔 T 日开盘涨停，还 `lu |= liq & blocked_buy[i+1]` —— 名单在 T 日收盘就定了，却拿 T+1 开盘的一字板回头砍 T 日的候选池。等于"知道明天买不进，今天就不选它"，是未来函数。

**整改**：删掉 `i+1` 分支，截面池只用 ≤T 可得数据（停牌/ST/hfq 缺口/上市天数/流动性/T 日涨停/质量否决）。T+1 到底成不成交，交给 `backtest.run_backtest` 在成交日按 `blocked_buy` 判断 —— 那是执行层信息，本来就不该进筛选层。

**影响范围（诚实说明）**：`build_universe` 是所有回测的公共入口，所以 004C 五窗数字也随之重算（+3.82pp → **+4.32pp**，MDD −29.59% → **−29.67%**，verdict 仍 fallback）。005S 侧只有 2024-10 一个截面受影响（该月恰好有 T+1 一字板被误剔），其余 59 个月逐月数字完全不变：

| 项 | 整改前 | 整改后 |
|---|---:|---:|
| 防守月 | 5/60 | 5/60（同 5 个月） |
| 观察名单 | 4/5 = 80% | 4/5 = 80%（2024-10 超额 +1.55% → +2.21%） |
| 避雷名单 | 2/5 = 40% | 2/5 = 40%（2024-10 收益 +3.37% → +6.27%） |
| 灯误报 / 漏报 | 0/5、8/60 | 0/5、8/60 |

**结论没变**：观察过线、避雷不达标。但**所有旧数字作废**，包括 005S-1 产物里那份。本报告与 `005S-2` 产物是唯一有效版本。

**月度名单落盘**：`out/005s_monthly_lists.parquet`，长表 `month / formed_at / list_type / rank / code / n_universe`，60 个月 × 2 张名单 × 100 只 = 12000 行，不含任何收益字段 —— 审计C 可自行取价复算，不必信我们的月度统计。
